  | 0 |                          KRUUOLQ                                 |
   \_/                           -------                                 |
     |                  Der oberste Meister des Chaos                    |
     |                                                                   |
     | Kruuolq ist der oberste Meister der Chaos-Gilde. Er ist schon     |
     | sehr alt und lehrt seine unheiligen Faehigkeiten den Kriegern des |
     | des Chaos, um durch sie die Saat des Boesen in dieser abscheulich |
     | guten Welt aufgehen zu lassen.                                    |
     |                                                                   |
     | Er besitzt ausfuehrliche Informationen zu den Zauberspruechen und |
     | den Daemonen. Auch erfaehrt jeder Krieger von ihm den aktuellen   |
     | Stand seiner Faehigkeiten und kann bei ihm seinen Gildenlevel     |
     | erhoehen, beziehungsweise erfaehrt, was man noch alles tun muss,  |
     | um diesen erhoehen zu koennen.                                    |
     |                                                                   |
     | Das Abfragen der Faehigkeiten geht uebrigens auch aus der Ferne.  |
     | Es reicht schon aus, Kruuolq nach <erhoehe> oder <faehigkeiten>   |
     | zu fragen beziehungsweise ihm dies mitzuteilen.                   |
     |                                                                   |
     | Nach dem Erhoehen des Gildenlevels lernt man bei ihm neue Zauber  |
     | und Daemonen, auch ist er zustaendig fuer die Gildenquests, die   |
     | man ab einem bestimmten Gildenlevel zum Erhoehen machen muss.     |
