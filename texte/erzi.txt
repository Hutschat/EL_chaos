  | 0 |                   DER ERZMEISTER DES CHAOS                       |
   \_/                    ------------------------                       |
     |      ... und die viel wichtigere Frage, wie werd ich einer?       |
     |                                                                   |
     | Voraus ein paar Worte zum Posten des Erzmeisters innerhalb der    |
     | Gilde der Krieger des Chaos.                                      |
     |                                                                   |
     | Als 'Erzmeister des Chaos' darf sich nur derjenige bezeichnen,    |
     | der seine ueberragenden Faehigkeiten in der Kunst des Boesen in   |
     | einem harten und lebensbedrohlichen Kampf gegen andere Mitglieder |
     | der Gilde bewiesen hat.                                           |
     |                                                                   |
     | Gemeinhin wird dieser Posten auch als Gilden-Level 12 bezeichnet, |
     | was ein bisschen irrefuehrend ist, da ganz andere Voraussetzungen |
     | erfuellt werden muessen, um ihn zu erlangen.                      |
     |                                                                   |
     | Das Wichtigste vorweg. Es kann immer nur einen Erzmeister des     |
     | Chaos geben. Er ist aller Oberhaupt und geniesst gewisse Vor-     |
     | rechte. Gefragt ist sein Wissen und gebannt lauschen die kleinen  |
     | Chaoten und winden sich vor Lachen wenn der Erzmeister von seinen |
     | neusten daemonischen Gemeinheiten erzaehlt.                       |
     |                                                                   |
     | Doch nun zum Weg dorthin.                                         |
     |                                                                   |
     | Das Leben eines richtigen Chaoten ist innerhalb der Gilde nicht   |
     | mit Erreichen des elften Ranges zuende. NEIN!                     |
     | Es gibt da diesen verlockenden Posten des 'Erzmeisters' als       |
     | Moeglichkeit, all sein erlerntes Wissen und Koennen ob der boesen |
     | und unheiligen Maechte im fairen Wettstreit unter Beweis und im   |
     | Vergleich zu Mitstreitern zu stellen und im Falle des Erfolges    |
     | diesen hochangesehenen Posten zu bekleiden und die Gilde zu       |
     | fuehren.                                                          |
     |                                                                   |
     | Fuer den sogenannten Erzmeister-Kampf muessen sich mindestens     |
     | drei Meister des Chaos (also Gilden-Level 11'er) bei Kruuolq fuer |
     | diesen Kampf anmelden. Fall sich keine drei finden sollten, wird  |
     | der Kampf sofort abgebrochen. Verstaendlich, denn fuer zwei Leute |
     | ist ja die Arena in der Wueste ausgelegt.                         |
     |                                                                   |
     | Haben sich nun drei wackere Meister gefunden und den Kampf ange-  |
     | meldet, so haben sie noch exakt eine Stunde Zeit um sich bessere  |
     | Ausruestung zu besorgen, einen Happen zu essen oder sich durch    |
     | diverse Rituale auf diesen Kampf vorzubereiten.                   |
     |                                                                   |
     | Der Erzmeister-Kampf findet nicht in der gewoehnlichen Arena der  |
     | Gilde statt, sondern an einem geheimen Ort, an den die Teilnehmer |
     | zu Beginn gebracht werden.                                        |
     |                                                                   |
     | Im Kampf um den Erzmeister-Rang sind Waffen wie Wurfsterne,       |
     | Pfeile und andere Artillerie verboten, da es hierbei um den       |
     | Beweis geht, wie gut man mit dem erlernten Wissen der Gilde umzu- |
     | gehen weiss.                                                      |
     |                                                                   |
     | Nachdem die Kontrahenten in der geheimen Arena angekommen sind,   |
     | beginnt augenblicklich der Kampf, wobei jeder gegen jeden         |
     | kaempfen kann und soll. Aus verstaendlichen Gruenden kann dieser  |
     | Kampf nicht von aussen, wie bei den normalen Kaempfen zur Er-     |
     | hoehung des Gilden-Levels, verfolgt werden.                       |
     |                                                                   |
     | Der Kampf ist erst dann beendet, wenn zwei der Kontrahenten ge-   |
     | flohen oder gestorben sind. Der uebrig gebliebene ist automatisch |
     | neuer Erzmeister des Chaos und darf diesen Titel tragen.          |
     |                                                                   |
     | Mit dem Titel verbunden ist die einzigartige Moeglichkeit, einen  |
     | neuen, maechtigen und unheilvollen Daemonen namens Yrintri be-    |
     | schwoeren zu koennen. Ausserdem ist der Chaosdaemon der chaotisch |
     | mutierten Haut dem Erzmeister unterwuerfig und bereitet ihm nicht |
     | den geringsten Kummer. Nicht zu verachten ist auch der 'Erz-      |
     | meister-Raum' im Obergeschoss der Chaosfestung, der Besonderheit- |
     | en aufweist und fuer keinen anderen Chaoten zugaenglich ist.      |
     |                                                                   |
     | Zu der grossen Ehre kommt also nicht nur der Ruhm sondern auch    |
     | nicht von der Hand zu weisende Vorteile fuer den Inhaber dieses   |
     | Ranges.                                                           |
     |                                                                   |
     | Allen Neulingen im Range eines 'Meisters des Chaos' sei nahe-     |
     | gelegt, sich eingehend auf einen Erzmeister-Kampf vorzubereiten   |
     | und diesen bei jeder sich bietenden Gelegenheit auch mitzumachen. |
     |                                                                   |
     | Aeltere Chaoten erklaeren sicher gern das ein oder andere zu den  |
    _| Regeln des Kampfes.                                               |
