  | 0 |           NUETZLICHE ZUTATEN FUER BOESE BESCHWOERUNGEN           |
   \_/            --------------------------------------------           |
     |                                                                   |
     | Die Zutaten beschraenken sich auf die Anwendung beim Zeichnen von |
     | Pentagrammen und Bannkreisen.                                     |
     |                                                                   |
     | Je magischer und maechtiger die verwendete Zutat ist, desto       |
     | staerker die Bannkraft des Konstrukts. Bei den kleineren Daemonen |
     | ist die Wahl der richtigen Zutat noch nicht so wichtig, aber bei  |
     | den starken und aeusserst boesen Daemonen sollte schon darauf     |
     | geachtet werden, was fuer das Beschwoerungsritual verwendet wird. |
     |                                                                   |
     | Einige Zutaten fuer das Ritual bekommen die Krieger des Chaos bei |
     | Achtarch dem Haendler hier in der Festung. Andere Zutaten dagegen |
     | sind nur schwer zu besorgen und ueber diese ganze Welt zerstreut  |
     | zu finden.                                                        |
     |                                                                   |
     | Es sei nocheinmal darauf hingewiesen, wie gut ein Pentagramm und  |
     | ein Bannkreis wird, haengt von der Zutat und dem Bannzauber ab,   |
     | den man darauf spricht.                                           |
     |                                                                   |
     | Genauso wichtig wie das Material aus dem ein Pentagramm besteht,  |
     | ist es, aus welchem Material der Bannkreis gezeichnet             |
     | wird. Im Folgenden seien einige nuetzliche Zutaten dafuer         |
     | erwaehnt:                                                         |
     |                                                                   |
     | Haut einer Kroete, Kreide, Daemonenschleim, blaue Bleistifte,     |
     | schwarze Bleistifte, Silberstaub, Staub eines Streitkolbens,      |
     | feiner, schwarzer Sand, Goldstaub, Drachenblut, verschiedene      |
     | Chaosfarben, farbiges Eis, Drachensabber und Knochenmehl.         |
     |                                                                   |
     | Zur Verbesserung der Schutzwirkung koennen nachtraeglich noch     |
     | schwarze Kerzen oder Augen eines Wasserunwesens in das Penta-     |
     | gramm gelegt werden.                                              |
     | Die eben aufgefuehrte Liste an Zutaten erhebt natuerlich nicht    |
     | den Anspruch auf Vollstaendigkeit, es wurden nur die Bekanntesten |
     | genannt.                                                          |
