  | 0 |                     DIE KAMPFARENA DES CHAOS                     |
   \_/                      ------------------------                     |
     |                                                                   |
     | Die gefuerchtete Kampfarena der Chaosfestung hat jeder Chaot      |
     | bereits vor seiner Aufnahme in diese Gilde von innen gesehen.     |
     |                                                                   |
     | Hier werden die kaempferischen Faehigkeiten der Mitglieder oder   |
     | der Anwaerter getestet. Im Grunde genommen ist die Arena nur ein  | 
     | leerer Raum mit sandbedecktem Boden. Das einzig auffaellige ist   |
     | ein riesiges Schild welches auf einen Knopf zeigt.                |
     |                                                                   |
     | Zum Beginnen der Kampfpruefung wird dieser Knopf gedrueckt. Der   |
     | Pruefer erscheint dann sofort. Dies ist in den meisten Faellen    |
     | Yruruu oder, fuer die hoeheren Raenge, Ziumtu.                    |
     |                                                                   |
     | Die Pruefer sind wegen ihres harten und gerechten Pruefungsstils  |
     | bekannt, beschwert hat sich noch niemand, was denn auch nicht     |
     | moeglich ist, da diejenigen schnell das Zeitliche gesegnet haben. |
     | Yruruu und Ziumtu richten den Kampf nach der Ausstattung, Konzen- |
     | trationsstaerke und Konstitution ihre Prueflings. Das dies jedoch |
     | keine Aufforderung ist, mit sehr schlechter Ausruestung einen     |
     | Kampf bestreiten zu wollen, versteht sich hoffentlich von selbst. | 
     |                                                                   |
     | Es besteht die Moeglichkeit, waehrend eines Kampfes aus der Arena |
     | zu fliehen, jedoch muss der Kampf dann natuerlich zu einem        |
     | anderen Zeitpunkt nachgeholt werden.                              |
     |                                                                   |
     | Prinzipiell besteht fuer alle Krieger des Chaos die Moeglichkeit, |
     | einem Mitstreiter von der Tribuene aus bei seinem Unterfangen     |
     | beizustehen und seine Bemuehungen, sich moeglichst nicht laecher- |
     | lich zu machen, zu verfolgen.                                     |
     | Einzig Erzmeister-Kaempfe unterliegen hier besonderen Regeln, die |
     | an anderer Stelle genauer erlaeutert werden.                      |
