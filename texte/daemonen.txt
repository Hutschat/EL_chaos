  | 0 |                        DIE DAEMONEN                              |
   \_/                         ------------                              |
     |                                                                   |
     |    Die Krieger des Chaos haben die einzigartige Moeglichkeit,     |
     |   Daemonen aus einer anderen Dimension zu holen und diese fuer    |
     |   bestimmte Zwecke einzusetzen. Grundlage einer jeden Daemonen-   |
     |   beschwoerung ist das Zeichnen eines Pentagrammes, Bannkreises   |
     |   und das Sprechen eines Bannzaubers.                             |
     |   Je besser die verwendeten Zuaten sind, desto mehr wird der      |
     |   einem auch erzaehlen koennen.                                   |
     |                                                                   |
     | Folgende Daemonen koennen beschwoert werden:                      |
     |                                                                   |
     |   Orakeldaemon   : Ab Gildenstufe 4  (KPs: 10)                    |
     |   Schattendaemon : Ab Gildenstufe 7  (KPs: 50)                    |
     |   Lichtdaemon    : Ab Gildenstufe 8  (KPs: 50)                    |
     |   Feuerdaemon    : Ab Gildenstufe 9  (KPs: 90)                    |
     |   Saeuredaemon   : Ab Gildenstufe 10 (KPs: 120)                   |
     |   Blutdaemon     : Ab Gildenstufe 11 (KPs: 140)                   |
     |   Wandler        : Nur fuer den Erzmeister (KPs: 180)             |
     |                                                                   |
     | Ein Daemon hat keinen festen Namen. Man ruft einen Daemon einer   |
     | bestimmten Art herbei, und es erscheint einer, der gerade Lust    |
     | hat - mit seinem eigenen Namen. Beschworen wird mit               |
     | 'beschwoere <art> [leise]', z.B. 'beschwoere feuerdaemon'.        |
     |                                                                   |
     | Sprueche und Daemonen lernt man bei Kruuolq mit dem Befehl        |
     | <lerne spruch> und <lerne daemon>.                                |
     |                                                                   |
     |                     x-x-x-x-x-x-x-x-x-x-x-x                       |
     |                                                                   |
     | Orakeldaemon:                                                     |
     | Der Orakeldaemon sieht, was anderen verborgen bleibt. Man fragt   |
     | ihn einfach: Ueber Monster weiss er schon fuer junge Chaoten      |
     | etwas zu sagen, ab Gildenstufe 5 auch ueber Gegenstaende und      |
     | Pentagramme, und ab Stufe 7 erzaehlt er einem sogar etwas ueber   |
     | den eigenen Koerper. Gibt man ihm einen Gegenstand, schaut er     |
     | ihn sich genau an.                                                |
     |                                                                   |
     | Syntax: 'frage <name> nach <monster|gegenstand|pentagramm|mir>'.  |
     |                                                                   |
     | Schattendaemon:                                                   |
     | Ein flinker und hinterhaeltiger Kaempfer aus dem Zwielicht. Er    |
     | kaempft einige Runden mit, haelt aber selbst keine Schlaege ab.   |
     |                                                                   |
     | Lichtdaemon:                                                      |
     | Kein guter Kaempfer, aber er kann einiges einstecken, ehe er      |
     | wieder verschwindet.                                              |
     |                                                                   |
     | Feuerdaemon:                                                      |
     | Ein recht starker Kaempfer, der im Dunkeln leuchtet. Man sollte   |
     | ihn besser nicht anfassen.                                        |
     |                                                                   |
     | Saeuredaemon:                                                     |
     | Ein aeusserst gefaehrlicher Kampfdaemon, dessen aetzende          |
     | Schleimhaut bei Beruehrung schwere Verletzungen hervorruft.       |
     |                                                                   |
     | Blutdaemon:                                                       |
     | Wild, gefaehrlich und ueberall wegen seiner Blutgier              |
     | gefuerchtet. Nur die allerbesten Krieger des Chaos duerfen ihn    |
     | beschwoeren.                                                      |
     |                                                                   |
     | Wandler:                                                          |
     | Werd Erzmeister! :)                                               |
     |                                                                   |
     |                         x-x-x-x-x-x-x-x-x                         |
     |                                                                   |
     | Man kann seinem Daemon verschiedene Sachen befehlen. Dies geht    |
     | immer mit 'befehle <daemonenname> <befehl>.                       |
     | Als Befehle stehen folgende Kommandos zur Verfuegung:             |
     |                                                                   |
     | folge, stop, folge leise, toete <name>, verschwinde, schweig,     |
     | sprich, wirf <objekt> weg                                         |
     | <objekt> kann dabei 'waffe', 'ruestungen' oder 'alles' sein       |
     |                                                                   |
     | Bei 'toete' greift der Kampfdaemon den Gegner an, man selbst      |
     | aber auch!                                                        |
     |                                                                   |
     |                        x-x-x-x-x-x-x-x-x                          |
     |                                                                   |
     | Es gibt auch noch einige kleinere Daemonen die bei Misslingen     |
     | einer Beschwoerung oder auch nur einfach mal so ihren Weg aus     |
     | der Daemonendimension finden, um die Krieger des Chaos zu aergern.|
     | Diese Daemonen sind im Allgemeinen recht einfach wieder los       |
     | zu werden. Bei ihnen handelt es sich insbesondere um:             |
     |                                                                   |
     | Uebmatu, Hothrog, Daedhel, Chochos, Rythoth und Anthukt           |
     |                                                                   |
     | In letzter Zeit wurde auch vermehrt ueber den Schutz der Daemonen |
     | nachgedacht und man munkelt, dass es jetzt Ruestungen und sogar   |
     | Waffen fuer sie geben soll. Wo diese allerdings zu finden sind,   |
     | konnte nicht herausgefunden werden.                               |
    _| Zum Schluss sei noch angemerkt, dass Daemonen Uebelwein sehr      |
   / \  gerne moegen.                                                    |
