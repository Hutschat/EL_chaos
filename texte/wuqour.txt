  | 0 |                           WUQOUR                                 |
   \_/                            ------                                 |
     |            Der Meister der Rituale und Beschwoerungen             |
     |                                                                   |
     | Wuqour ist der Meister der Rituale und Beschwoerungen innerhalb   |
     | der Gilde der Krieger des Chaos. Er befindet sich meist in seinem |
     | Beschwoerungsraum noerdlich der Halle.                            |
     | Es gibt viele verschiedene Arten sich von Wuqour helfen zu        |
     | lassen und fuer hartnaeckige Frager hat er auch einige angenehme  |
     | Ueberraschungen parat.                                            |
     |                                                                   |
     | Wuqour kann auf ein Pentagramm einen Kreiszauber sprechen,        |
     | wodurch dieses maechtiger wird. Das funktioniert natuerlich nur   |
     | in bestimmten Abstaenden.                                         |
     |                                                                   |
     | Auch kann er den Chaosdaemon der Chaosruestung vertreiben indem   |
     | er ihn erweckt, was hilfreich ist, wenn man Kontrolle ueben       |
     | moechte.                                                          |
     |                                                                   |
     | Er hat ausfuehrliche Informationen zu den verschiedenen Daemonen  |    
     | und Beschwoerungen. Wenn man etwas ueber Pentagramme, Bannkreise  |
     | oder Bannzauber wissen moechte, sollte man nicht zoegern, sich an |
     | an ihn zu wenden. Wuqour hilft sicher gern, auch bei der Ver-     |
     | besserung von Pentagramm und Bannkreis, wenn man ihn um eine      |
     | Beurteilung bittet.                                               |
     |                                                                   |
     | Bei alledem sollte man es jedoch nicht versaeumen auch hoehere    |
     | Raenge der Gilde zu befragen, was natuerlich auch fuer alle       |
     | anderen Mitarbeiter der Gilde gilt. Fragen kostet nichts.         |
